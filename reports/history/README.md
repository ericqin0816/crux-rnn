# CruxRNN: historical documents

The `prior_*` files are preserved byte-for-byte from post-execution commit `2673c9ca11ca9fc701a1d13129f0cb371385ea70`. Their original titles and final-result descriptions are historical evidence from before the later CruxRNN naming and pilot approval gate. SHA-256 values are in `provenance/stages.json`.

Current documentation is in `README.md`, `RUN_REPORT.md`, and the parent `reports/` folder. Read `reports/prior_execution.md` for the chronology. Do not confuse preservation of a previous final execution with approval for an additional final experiment.
